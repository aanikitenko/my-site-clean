## Что такое библиографический менеджер?

Это программа для хранения и форматирования научных ссылок.

## Популярные менеджеры

1. **Zotero** — бесплатный, с расширением для браузера, поддерживает ГОСТ
2. **Mendeley** — бесплатный, социальная сеть для учёных
3. **JabRef** — для LaTeX/BibTeX

## Оформление по ГОСТ

Книга: Фамилия И.О. Название. — Город: Издательство, Год.

Статья: Фамилия И.О. Название // Журнал. — Год. — №. — С.

## Заключение

Библиографические менеджеры экономят время на форматирование списка литературы.
